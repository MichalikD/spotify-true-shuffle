# Installation

> **Audience:** End Users

This guide describes the recommended installation process for Spotify True Shuffle.

Spotify True Shuffle consists of multiple Apple Shortcuts and Scriptable modules.  
The **Spotify True Shuffle Installer** handles most of the installation automatically.

By the end of this guide you will have:

- all required Apple Shortcuts
- all required Scriptable modules
- a Spotify Developer application
- a valid Spotify True Shuffle configuration
- working Spotify authentication
- your first successful shuffle

---

# Prerequisites

Before starting, make sure you have:

- an iPhone or iPad
- Apple Shortcuts
- Scriptable
- iCloud Drive enabled for Shortcuts and Scriptable
- a Spotify Premium subscription
- a Spotify Developer account

A GitHub account is **not required** for normal installation.
